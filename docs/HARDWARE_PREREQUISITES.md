# Hardware Prerequisites
- `200 Mb` memory for launcher
- `4 Gb` memory for Minecraft (plus about `1 Gb` for Wine/Proton)
- `150 Mb` storage for launcher
- `200 - 800 Mb` storage for Minecraft (1 version), about `1 Gb` per Wine prefix
- `x64` architecture
- At least `Intel Celeron J4105` or `AMD FX-4100`
- A GPU with Vulkan 1.3 support for DXVK (Intel HD 500 series / AMD GCN / NVIDIA Kepler or newer); older GPUs can turn DXVK off in Settings > Linux and use OpenGL (slower)
